# Web Cartridge Countdown

Spider-Man loads N web cartridges before a rooftop showdown. Each cartridge fires one web, and he counts down as each shot is fired.

Given an integer `N`, print the numbers from `N` down to 1, each on its own line. After the countdown, print `WEB'S OUT!` on the final line.

## Input Format

The first and only line contains a single integer `N`, representing the number of web cartridges.

## Output Format

Print:
* The numbers from `N` down to 1, each on its own line.
* `WEB'S OUT!` on the final line after the countdown.

## Constraints

* `1 <= N <= 1000`

## Sample Input 1

```
4
```

## Sample Output 1

```
4
3
2
1
WEB'S OUT!
```

## Explanation 1

Starting from 4, Spider-Man fires each web and counts down to 1. After the final web is fired, he announces `WEB'S OUT!`.

## Sample Input 2

```
3
```

## Sample Output 2

```
3
2
1
WEB'S OUT!
```

## Explanation 2

Starting from 3, Spider-Man counts down through 3, 2, and 1. After the countdown, `WEB'S OUT!` is printed.
