# Spider-Man's Reversed Web Signal

Spider-Man receives a numeric signal from one of his web-shooters, but the signal has been transmitted in reverse. Peter needs to reverse the number to decode the message correctly.

Given an integer `N`, reverse its digits and print the resulting number.

## Input Format

The first and only line contains a single integer `N`, representing the numeric signal.

## Output Format

Print a single line containing the reversed number.

## Constraints

* `0 <= N <= 10^9`

## Sample Input 1

```
12345
```

## Sample Output 1

```
54321
```

## Explanation 1

The digits of 12345 are reversed to get 54321.

## Sample Input 2

```
9080
```

## Sample Output 2

```
809
```

## Explanation 2

Reversing 9080 gives 0809. Leading zeros are omitted when printed, so the output is 809.
