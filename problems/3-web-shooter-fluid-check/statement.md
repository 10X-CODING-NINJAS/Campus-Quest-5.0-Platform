# Web-Shooter Fluid Check

Peter Parker is ready to swing across the city, but first, he checks his web-fluid level to make sure he has enough for a safe journey.

Given an integer `F` representing the current web-fluid level, determine whether Spider-Man should swing or recharge. If the web-fluid level is 50 units or more, print `SWING`. Otherwise, print `RECHARGE`.

## Input Format

A single line containing one integer `F`.

## Output Format

Print `SWING` or `RECHARGE`.

## Constraints

* `0 <= F <= 1000`

## Sample Input 1

```
65
```

## Sample Output 1

```
SWING
```

## Explanation 1

`F = 65` which is greater than 50, so Spider-Man swings.

## Sample Input 2

```
30
```

## Sample Output 2

```
RECHARGE
```

## Explanation 2

`F = 30` which is less than 50, so he must recharge first.
